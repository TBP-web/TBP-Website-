Publish Your Changes

Edits you save in this panel are stored only in this browser. To push them to the live website for every visitor, download the content file and replace assets/js/content.js in your hosting/repository, then deploy.

  1. Make and Save your edits in the tabs on the left.
  2. Click Download content.js below.
  3. Replace assets/js/content.js with the downloaded file.
  4. Deploy (push to Git, or re-upload the folder). Done — it's live.

Admin Passcode

Changes the passcode for this panel. This is light protection only — anyone can read it in the page source. For real access control, password-protect /admin.html at your host (see README).
